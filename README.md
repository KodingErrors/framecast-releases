# Framecast for Android

Downloads of the Framecast Android app. This repository holds builds only; the source code is private.

**Latest version:** [Framecast.apk](https://github.com/KodingErrors/framecast-releases/releases/latest/download/Framecast.apk)

All versions are on the [Releases](https://github.com/KodingErrors/framecast-releases/releases) page.

## Installing

1. Open the link above on the phone and download `Framecast.apk`.
2. Open the file. When Android asks, allow installs from your browser or file manager.
3. Open Framecast and allow notifications. The "Framecast is running" notification keeps it serving while the screen is off; its **Stop** button ends it.

For 64-bit phones with Android 8 or later.

The app does nothing on its own beyond your phone: each install creates its own access secret, and only devices you share a link with (over Tailscale) can reach it.
